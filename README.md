# Purushottam — Three.js 3D Portfolio

A creative, high-animation portfolio built with HTML, CSS, JavaScript, Three.js and GSAP.

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Run `index.html` with Live Server.
4. Keep internet on because Three.js and GSAP are loaded from CDN.

## Included local media
- `assets/purushottam.jpeg` — provided portrait photo.
- `assets/purushottam-showreel.mp4` — provided video, used in the hero, showreel and as a Three.js video texture.
- `assets/video-poster.jpg` — generated poster frame for faster visual loading.

## Main features
- Fixed Three.js particle universe
- Mouse-reactive 3D camera
- Three.js photo texture plane
- Three.js video texture plane
- Abstract torus-knot sculpture and wireframe objects
- GSAP + ScrollTrigger section reveals and parallax
- 3D tilt cards and magnetic buttons
- Animated skills orbit
- Cinematic showreel section
- Project cards with live links
- Experience, services, process, product-thinking and contact sections
- Responsive mobile menu
- Reduced-motion accessibility fallback
